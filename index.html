01. About Me

我的主线是 AI Agent 应用工程：用 Go / Python / FastAPI / React 把 LLM、工具调用、任务状态、评估指标和前端交互串成完整产品，而不是停留在一次性的 prompt demo。

当前项目覆盖三类能力：Agent Runtime 框架（CareerPilot — Go + Wails 桌面 App）、全栈 Agent 工作台（LifeHelper — 105 测试 + 8 工具 + 会话回放）、多 Agent 视频工作流（Short Video Studio — 9 阶段 pipeline + Provider 抽象）。

我在求职中更希望被评价为"能把 AI 能力落到业务流程里的人"：知道怎么做降级、怎么写测试、怎么设计公开版和私有版边界，也能把项目整理成可复现、可解释的工程展示。

正在寻找 2026-2027 AI Agent / 后端工程实习机会，地点北京优先，上海 / 苏州可考虑。
